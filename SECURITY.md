# Security model

The extension operates on subscription quota metadata, not messages or API billing. Runtime code is bundled locally with no external dependencies, eval, inline scripts, remote fonts, content scripts, cookie-reading APIs, native executables, or credential exports. Extension-page CSP restricts connections to Claude and ChatGPT; the HTTP helper further restricts URLs to exact quota/discovery/session path patterns. It only sends GET with Accept: application/json and browser-managed credentials. Codex also sends an in-memory bearer token only to the exact WHAM usage endpoint on chatgpt.com; the HTTP helper rejects authorization on all other paths. It disables caching, rejects redirects, and enforces timeouts. Raw responses and errors are not persisted or logged. Provider strings render through textContent rather than innerHTML.

Local storage and the Firefox profile are trusted for this threat model. Device compromise, hostile browser modifications, or a service returning incorrect reported usage are outside the extension's ability to prevent. Browser host permission is origin-wide even if only a few routes are used. Private browsing is disabled to avoid mixing profiles. An existing website sign-in is not proof that background requests will authenticate, especially in containers or under cookie partitioning.

The user explicitly authorized in-memory Codex session authentication for v1.0.1. Session JSON remains local to the provider call; only quota metadata and a validated account ID are returned. Never persist, log, export or relay the session response or token. Do not add manual cookie input, API keys, page interceptors, remote relays or native credential readers as silent fallbacks. Further authentication changes require explicit review and real-account validation.

When reporting a security issue, use a private reporting channel supported by the eventual repository host. Never post your cookies, tokens, personal organization IDs, or a full browser profile in an issue. This starter repository has no configured remote or maintainer contact yet. Sanitized symptoms and affected source paths are sufficient for initial triage.
